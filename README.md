# 프랑스어 발음 연습 사이트

프랑스어 단어와 문장을 카드로 보고 음성을 들을 수 있는 정적 웹사이트입니다. `editor.html`에서 개발 지식 없이 레슨, 섹션, 카드와 음성을 편집할 수 있습니다.

## 사용

- 학습 화면: `index.html`
- 관리자 편집 화면: `editor.html`
- 자세한 설명: `사용방법.md`

편집 화면의 `GitHub에 저장` 기능을 처음 사용할 때 저장소와 fine-grained personal access token을 연결하세요. 이후에는 버튼 한 번으로 레슨 데이터와 음원을 이 저장소에 커밋할 수 있습니다.
